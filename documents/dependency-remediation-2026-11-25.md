## Validation and release gate

Draft PR validation generates a candidate lock via npm, runs npm ci, npm ls, tests, build and captures audit JSON. It uploads the lockfile and audit for review; it cannot commit or deploy. The existing Firebase preview job skips drafts. Before marking ready, review the generated lockfile, commit it, run the checks against that committed lockfile, compare baseline and post-patch audit, and manually smoke-test routes, Auth0, and todo flows. The normal Firebase preview behavior on non-draft PR updates is unchanged; do not mark ready or update a non-draft PR until deployment is authorized. No npm audit fix --force or manual lockfile editing.
